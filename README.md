# Abhijit Singh — Portfolio

A responsive, interactive developer portfolio for Abhijit Singh, an AI/ML-focused Computer Science graduate and AI Intern at CDAC Mohali.

## Overview

This portfolio presents Abhijit's experience, education, technical skills, projects, and contact links through a dark, editorial-inspired interface with 3D motion accents and a light-theme alternative.

- Skills grouped by languages, frameworks, libraries, data, databases, and tools

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```text
app/
├── page.tsx       # Portfolio page and interactive sections
├── globals.css    # Theme tokens, responsive styles, and visual effects
└── layout.tsx     # Metadata and root layout
public/
└── ...            # Static assets such as the resume
```
